## Браузерный запуск

В `_layouts/lesson.html` общий формат урока и ссылка на квиз соответствующего курса. Урок может указывать `browser_runtime: '9'` или `'10'`. Внутри браузера используется компилятор C# на Roslyn/WebAssembly. При добавлении нового урока нужны адаптер исполняемого примера и тест.

Под самим редактором встроена **своя кнопка запуска текущего кода**. Кнопка под примером переносит стартовый код, а после редактирования можно запускать его повторно без перезагрузки исходника. Также доступно Ctrl+Enter.

Каждая из опубликованных самостоятельных задач содержит в Markdown урока полноценный C#-шаблон: `Main`, входные данные, явные `Assert`, проверку границ и место для метода ученика. Кнопка «Запустить и проверить Assert» вставляет метод в шаблон и открывает **весь C#-код, включая проверки**, в браузерном редакторе. Дополнительный JS-тестовый движок не нужен: `course-runner.js` только собирает текст программы. Готовое решение практики не публикуется.

## Pipeline

`.github/workflows/pages.yml` кеширует WebAssembly-компиляторы .NET 9 и .NET 10 независимо. Ключ учитывает pinned upstream revision, скрипт подготовки и соответствующий исходный пример, встроенный в компилятор. Правки Markdown, CSS, вопросов или общего JavaScript не вызывают пересборку WASM при попадании в кеш. На первом запуске или после инвалидации компиляторы собираются снова. Каждый коммит всё равно запускает Jekyll, smoke-тесты и полную публикацию GitHub Pages.

## Публикация

Settings → Pages → Build and deployment → Source: **GitHub Actions**.

Ожидаемый адрес: https://boyarincev.github.io/dotnet-courses/ .

Не помещайте в публичный GitHub рабочие секреты, конфиденциальные исходники, личные ответы и историю интервальных повторений. Черновики хранятся локально в браузере; персональный журнал курса ведётся в Google Docs.

Интервальное повторение на сайте теперь использует **ts-fsrs@6.0.0 (FSRS-7)** с адаптивными интервалами. У каждого вопроса есть постоянный `Q-ID`, привязка к `lesson_number` и отдельная карточка FSRS с историей и сроком следующего повторения. Из конкретного урока ссылка с `?through=N` выбирает случайные вопросы текущего и предыдущих уроков (просроченные и сложные прежде новых), при прямом открытии — весь курс. После заполнения ответа пользователь **сам** ставит «Неверно», «Частично», «Верно» или «Легко», и FSRS пересчитывает срок. Ответы/оценки локальные, браузерные, не отправляются автоматически в Google Docs; для смены устройства есть экспорт/импорт JSON. Старые интервалы 1/3/7/14/30/60 остаются в историческом журнале, но к новым самооценкам на сайте не применяются.
