# .NET Learning Lab — C# 13, 14, 15 и .NET 9, 10, 11

Практический курс для опытных разработчиков по C# 13, C# 14, C# 15 и .NET 9, .NET 10, .NET 11. Изучаем не весь changelog, а только полезные возможности, связанные учебными цепочками.

## Как устроено
- `_lessons/`: Markdown-уроки с запускаемыми примерами C# и самостоятельными заданиями.
- `/labs/001-browser/`: дополнительная версия первого урока с C#-компилятором в браузере (Roslyn + .NET 9 WebAssembly); исходный урок сохранён.
- `_data/questions.yml`: публичный банк вопросов с постоянными ID (без правильных ответов и личной истории).
- `quiz.md`: интерактивный квиз с экспортом ответов для проверки в ChatGPT.
- `.github/workflows/pages.yml`: сборка и публикация GitHub Pages.

## Запуск сайта
В GitHub открыть **Settings → Pages → Build and deployment → Source → GitHub Actions**. После этого workflow публикует сайт при изменениях в ветке main.

## Конфиденциальность
Репозиторий публичный. Никогда не коммитить сюда персональные ответы, историю интервальных повторений, секреты или рабочий код. Черновики могут храниться в localStorage одного браузера; для проверки их можно скопировать в ChatGPT. Персональный журнал остаётся в Google Docs вне этого репозитория.

## Контентная модель
Один выпуск: новые практически полезные возможности C# и .NET, запуск примера, маленькая задача на самостоятельный код и квиз. Приоритет — применимость, не хронология. По одной теме бывает несколько вопросов с разными ID. Даты повторов определяются после проверки каждого ответа: 1, 3, 7, 14, 30, 60 дней; ошибка — завтра; отсутствие ответа не ошибка.

## Добавление урока
Создай `_lessons/NNN-slug.md` с front matter (`lesson_number`, `title`, `summary`, `csharp_feature`, `dotnet_feature`, `series`, `lesson_date`). Добавь вопросы в `_data/questions.yml`. Проверяй код и не повторяй уже пройденные темы.

Локально: `gem install jekyll bundler`, затем `bundle install` и `bundle exec jekyll serve --baseurl ''`.
