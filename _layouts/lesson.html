Практика: настоящий C# в браузере

Под каждым C#-примером есть кнопка «Запустить этот пример». Она переносит код в редактор ниже, автоматически дополняя неполные фрагменты окружением для запуска. Твоё самостоятельное решение запускается отдельно, без заранее готового ответа.

Подсветка C#, парные скобки и базовые подсказки имён (Ctrl+Space). Это ещё не полноценный семантический IntelliSense с анализом типов.

Первая загрузка WebAssembly может занять больше времени. Код запускается в браузере и не отправляется на сервер компиляции. Не вставляй секреты. Браузерная среда не заменяет SDK для EF Core, ASP.NET Core и системных API.
